##  What it does

Bigy gathers the traces Windows leaves behind into **one clean list** and a simple `Report.txt`.

Other tools only show what still exists. Bigy also finds **deleted Prefetch and Recent files** and tells you when they were removed.

<br>



| | |
|---|---|
|  **Deleted files** | Finds removed Prefetch and Recent entries with the deletion time |
|  **Time ranges** | 1 hour, 2 hours, 24 hours, 7 days, 30 days, or everything |
|  **Search and filters** | Type to search, or show only matches or only deleted items |
|  **Keyword flags** | Suspicious names are highlighted in red |
|  **Dark app** | Clean interface that stays smooth while scanning |
|  **Report** | A plain text `Report.txt` is saved to your Desktop |

<br>

## 📖 How to use

1. Download the `.exe` from the [Releases](../../releases/latest) page
2. Run it and click **Yes** on the Administrator prompt
3. Choose a time range and your sources
4. Press **Start scan**

That's it. Results show up in the app, and the report is waiting on your Desktop.
